# open-atomic

An open-source C++20 reimplementation of Atomic Bomberman (1997).

This repository contains the plan and research notes. There is no playable open-atomic build yet.

## Start here

Read the [project discussion and work order](https://github.com/insellium/open-atomic/issues/24). It lists the tasks in development order. Issue numbers are card IDs.

1. Build the C++20 base, port gameplay and add the main menu.
2. Complete the original mechanics, bots and campaign; fix documented bugs.
3. Add modding, audio, content tools and package versions.
4. Add the planned local features and release a local build.
5. Develop online multiplayer and content sharing.

Run playtests and compare with the original throughout development.
